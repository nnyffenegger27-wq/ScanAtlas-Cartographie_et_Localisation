# Les acquisitions USB

Mesures réelles du LD06 utilisées pour les premières étapes. Le fichier de quatre scans est pris à la même position. Le fichier multiposition contient 14 scans, mais seulement quatre poses distinctes enregistrées : plusieurs scans restent à l’origine. Ne pas le considérer comme une carte entièrement recalée.
