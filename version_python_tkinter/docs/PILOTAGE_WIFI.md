# Pilotage Wi-Fi et cartographie directe

Le guide actuel est [GUIDE_SCANATLAS_V3.md](GUIDE_SCANATLAS_V3.md).

Le firmware utilise désormais huit sorties PWM configurables, et propose USB et Wi-Fi dans le même programme. Le relevé des GPIO, l’affectation des roues et les polarités restent à confirmer sur le robot. Les procédures de diagnostic sont détaillées dans le guide.
